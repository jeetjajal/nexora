🚀 Quick Local Development Commands

Run the full Nexora stack locally with isolated networking and persistent volumes:

# 1. Copy sample environment file
cp .env.example .env

# 2. Build backend container & start entire stack in detached mode
docker compose up -d --build

# 3. View live logs and container health
docker compose ps
docker compose logs -f backend

# 4. Gracefully tear down stack and preserve persistent volumes
docker compose down
